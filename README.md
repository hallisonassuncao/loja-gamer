# LH Games — Atividade Front-End SENAI

Projeto educacional de loja de eletrônicos e jogos gamer, desenvolvido a partir do ZIP inicial da atividade e orientações do PDF **CodFront_Ativ_HomeLogin**.

## Como abrir no VS Code

1. Extraia o ZIP final.
2. No VS Code, escolha **Arquivo > Abrir Pasta** e selecione `loja-gamer-senai`.
3. Abra `index.html` no navegador (ou use a extensão Live Server).
4. Clique em **Login** no menu para testar `login.html`.

**Atenção:** Bootstrap e jQuery são carregados por CDN; mantenha conexão com a internet para os componentes e efeitos funcionarem.

## Funcionalidades

- HTML5 semântico (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Bootstrap 5: navbar recolhível, grid, cards, botões e carrossel de três banners.
- CSS3 e media queries para desktop, tablet e celular.
- Seções: promoções/mais vendidos, novidades, galeria e rodapé.
- Pesquisa de produtos pelo nome, botões Comprar demonstrativos, voltar ao topo e formulário de novidades.
- Página de login com validação JavaScript e cadastro demonstrativo com efeito jQuery.

## Publicação no GitHub

1. Crie um repositório **público** no GitHub.
2. Envie todos os arquivos e pastas, mantendo a estrutura.
3. Em **Settings > Pages**, configure **Deploy from a branch**, `main`, `/ (root)` e salve.
4. Aguarde a publicação e teste o endereço exibido no GitHub Pages.
5. Cole no AVA o link do repositório ou do site publicado, conforme orientação do tutor.
